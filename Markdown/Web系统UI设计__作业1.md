# 一、Apple

**网站：** https://www.apple.com.cn/

## 1. 网站定位
消费电子领域的顶尖品牌官网与高端电商入口，旨在展示产品工业美学、传递品牌价值与引导购买。
## 2. 版式设计
极致的大卡片与超大留白（Negative Space）。采用单栏流式布局，配合全屏级的大图展示，摒弃了传统侧边栏，呈现极致的“杂志化”视觉体验。
## 3. 色彩设计
黑、白、极浅灰组成的无彩色（Achromatic）极简底色。色彩完全服务于产品本身，让产品渲染图的色彩（如 iPhone 的新配色）成为全屏唯一的视觉焦点。
## 4. 图像与图标设计
 行业顶级的 3D 渲染图与光影摄影，细节清晰可见；图标采用极简的单色线条风格（San Francisco 风格），矢量化程度高，精致且无冗余装饰。
## 5. 文字与信息层级
用苹果定制字体 SF Pro（中文字体为 PingFang SC）。文字字号对比极度夸张（超大标题 + 极简短句），信息层级拉得极开，实现“一屏只讲一个卖点”。
## 6. 交互与动态效果
视差滚动（Parallax Scrolling）与滚动驱动动画（Scroll-driven Animations）的行业标杆。随着用户向下滚动，产品零件自动拆解、组装或旋转，带来极强的沉浸感。
## 7. UI 设计优点
工业级的高级感与电影级视觉呈现，将“展示”与“交互”完美结合，塑造了科技行业的 UI 标准。
## 8. 我的第一印象

> 用着工程哲学设计的购买入口，高度契合苹果线下店一贯形成的风格，在不知不觉间，就筛选了客户。简洁、高效。 <br>  ~~*可惜就是点*~~ **贵。**

# 二、Huawei

**网站：** https://www.huawei.com/cn/

## 1. 网站定位
兼顾 B 端（企业级 ICT 解决方案）与 C 端（消费者业务）的全球科技巨头门户，强调技术实力、商业稳重与创新力。
## 2. 版式设计
 经典的 B 端企业大屏风与 C 端高端电商相结合的网格布局。顶部导航结构深厚，首屏多为宽屏轮播 Banner，下方按照“终端产品 - 行业解决方案 - 新闻动态”进行横向模块化分块。
## 3. 色彩设计
以高纯度的“华为红”（#C8102E）作为品牌标志色与点缀色，大面积采用纯白与浅灰背景，辅以深蓝/深灰表示商业稳重感。
## 4. 图像与图标设计
采消费电子侧使用高精度的产品图，B 端侧使用大量高科技感的大气摄影（如云服务器、5G 基站、智能园区场景）；图标采用线条与块面结合的商务风格。
## 5. 文字与信息层级
采用 HarmonyOS Sans 字体，字体排版严谨，标题与正文字号阶梯清晰，信息密度中等，兼顾了阅读效率与企业形象宣贯。
## 6. 交互与动态效果
导航栏支持多级巨型菜单（Mega Menu）展开； Banner 切换平滑，卡片悬停时有微弱的微动抬升效果（Hover Elevator Style），整体偏向稳重顺畅。
## 7. UI 设计优点
极其优秀的巨型企业门户导航架构，将复杂的 B/C 端业务线梳理得井井有条，大气且具有商业说服力。
## 8. 我的第一印象

> 比起Apple的简单明了，Huawei更像是一家企业，在主界面就有了各式各样的产品展示和服务支持。消费者往往要在3层以上的UI下才能找到自己真正需要的内容，引导性较差。但是队医吸引投资者和商业资本，确实炒了一盘不错的菜。

# 三、Github

**网站：** https://github.com/

## 1. 网站定位
全球最大的开源代码托管与开发者协作平台，强调高效、专业、工具属性与极客文化。
## 2. 版式设计
严谨的响应式网格布局。首屏（Hero Section）通常采用暗黑背景搭配动态代码/星系视觉；内页与功能区采用高度模块化的卡片与列表结构，边缘清晰。
## 3. 色彩设计
默认深色调（Dark Mode），背景以 **#0d1117**等极深灰蓝为主；以标志性的 GitHub 绿色（贡献图绿 **#2ea44f**）和亮蓝色作为核心点缀与 CTA 按钮色，视觉对比度极高，适合长时间代码阅读。
## 4. 图像与图标设计
采用自主开源的 Octicons 图标库，线条像素级精准、风格统一且极度轻量化；图像多为代码语法高亮框、渲染的 3D 拟态几何图形或 Git 节点拓扑图。
## 5. 文字与信息层级
使用等宽字体（Monospace）展示代码，无衬线字体（Sans-serif）展示UI文本；通过 h1-h6 的字号严格区分项目名称、Readme 标题与代码注释，层次极其分明。
## 6. 交互与动态效果
带有优雅的微交互（如 **Star** 按钮的点击动画、贡献度 **Grid** 的悬停 Tooltip）；网页支持全键盘快捷键导航，页面切换轻盈顺滑。
## 7. UI 设计优点
极出色的暗色模式调色盘，信息密度高却毫无杂乱感，极其符合开发者的高效操作习惯。

# 四、CSDN

**网站：** https://www.csdn.net/

## 1. 网站定位
中国最大的 IT 技术社区与开发者知识分享平台，主打技术博客、代码问答、在线课程与 IT 资讯，极度强调信息分发与商业变现。
## 2. 版式设计
典型的“三栏式”高密度社区布局。
## 3. 色彩设计
采用标志性的 “CSDN 红/橙”（⁠ **#FC5531**⁠）作为品牌标志色与核心 CTA（如“创作”、“关注”、“搜索”）按钮色；背景为浅灰色（ **⁠#F5F6F7**⁠），卡片采用纯白底色以形成视觉层级。整体色彩饱和度高，商业引导性极强。
## 4. 图像与图标设计
图像来源多元且略显杂乱，涵盖博主自定义的文章封面图、技术架构示意图、用户头像以及高彩度的商业推广Banner；图标采用标准的线性/面性技术图标（如代码、点赞、收藏、评论、下载等），风格偏向实用主义。
## 5. 文字与信息层级
文本信息密度极大。单个文章卡片内集成了多达 6–7 个信息层级（“原/转”标签、文章标题、摘要 preview、博主信息、阅读量、点赞数、评论数、发布时间等）。通过标题加粗黑体与灰色辅助字来进行主次区分。
## 6. 交互与动态效果
带有强烈的商业与社区引导交互：
页面向下滚动时，顶部搜索栏与右侧“热榜/回到顶部”控件会自动吸顶固定（Sticky Layout）；
文章列表支持悬停卡片变色/微抬升；
全站带有较多的弹窗提示（如登录引导、关注引导）与动态广告展位。
## 7. UI 设计优点
极高的信息分发效率： 经典的“三栏式”结构让开发者进入首页后，能以极快的速度在左侧选分类、中间看文章、右侧看热榜，精准获取所需技术解决方案；
标签化系统完善： 通过“原创”、“VIP”、“精选”等醒目标签，帮助用户迅速筛选内容品质。
## 8. 我的第一印象

> 结合了github和早期中国互联网的**导航页**的设计遗留，搜索功能占比小，推送、咨询、社区和广告占据了主页的绝大多数视觉板块。泡杯茶能看一下午。

# 五、USA.gov

**网站：** https://www.usa.gov/

## 1. 网站定位
美国联邦政府的统一服务门户，侧重于为民众提供“一站式”政务指南、办事入口与信息查询。
## 2. 版式设计
基于 USWDS（美国标准设计系统） 构建。采用大字号、单栏/双栏响应式卡片布局，极其注重移动端优先（Mobile-First）的自适应呈现。
## 3. 色彩设计
经典的红白蓝政务配色，但降低了饱和度（Navy Blue #1a4480 + Muted Red），辅以大面积浅蓝/浅灰色块底色，视觉感现代且轻松。
## 4. 图像与图标设计
图像多为代表美国多元文化的民众写实摄影，极具亲和力；图标采用 USWDS 统一的标准线条图标，语义极其明确。
## 5. 文字与信息层级
典型的西方现代无障碍排版。采用超大字号的无衬线字体，列表式展示“How do I...”（我该如何...）等问题，层级极少，直奔主题。
## 6. 交互与动态效果
极其注重可访问性交互。支持高对比度切换、字号放大，所有交互控件（按钮、输入框）都有极其明显的 Focus 聚焦边框状态。
## 7. UI 设计优点
现代无障碍设计的示范级标准，将复杂的政务信息转化为极其简单的“服务指南”，界面亲和力极强。

# 六、gov.cn

**网站：** https://www.gov.cn/

## 1. 网站定位
中华人民共和国国务院官方门户网站，承担权威信息发布、政策解读与政务服务的功能，要求极高的庄重感与易读性。
## 2. 版式设计
传统的“报刊式”三栏/两栏网格布局。顶部居中展示国徽与红头标识，首页分为“要闻”、“政策”、“服务”、“互动”等大型横向版块，版面规整统一。
## 3. 色彩设计
采用中国红（国徽与导航主色）与深蓝/墨灰作为核心基调，背景为纯白，整体配色庄重严谨，符合政务网站的标准公信力色彩。
## 4. 图像与图标设计
图片以高质量的高级会议摄影、政务活动现场照为主；图标使用极简的单色线性政务图标（如印章、文件、服务小人），去装饰化。
## 5. 文字与信息层级
字体以宋体/黑体为主，字号普遍偏大，行间距（Line Height）宽大；标题加粗极其醒目，非常注重信息的无障碍阅读（Accessibility）。
## 6. 交互与动态效果
极度克制。摒弃一切复杂的 3D 或滚动视差动画，采用稳定的 Tab 切换、文字滚动公告与清晰的搜索跳转，确保低网速与老龄用户的访问稳定。
## 7. UI 设计优点
信息表达极其严谨权威，无障碍适配优异，版块清晰度高，完美贴合国家级政务门户的职能定位。
## 8. 我的第一印象

> 绝大多数高校的网站设计和这个高度相似。

# 七、Amazon

**网站：** https://www.amazon.com/

## 1. 网站定位
全球最大的综合性电商平台，极度强调“搜索驱动”、“购买效率”与“算法推荐”。
## 2. 版式设计
典型的美式高密度网格布局。顶部为功能极其强大的超大搜索栏，首页由数十个小卡片（Dashboard-style Cards）拼接而成，最大化展示个性化推荐。
## 3. 色彩设计
以深蓝灰色（#131921）作为顶部导航，以标志性的 Amazon 橙色（#FF9900）作为搜索按钮、评价星级与 CTA（Add to Cart）主色，背景使用浅灰 (#EAEDED) 铺底以区分卡片。
## 4. 图像与图标设计
图像基本完全由第三方卖家上传的产品白底图构成，UI 本身不作过多图片修饰；图标采用非常标准的线性小图标，服务于分类指示。
## 5. 文字与信息层级
文字密度极大。使用 Ember 字体，通过粗细与颜色（深灰正文、红色价格、橙色星级）来划分信息优先级，视觉上稍显拥挤但检索效率极高。
## 6. 交互与动态效果
克制且偏向实用主义。极少使用酷炫的滚动动画，重点放在无缝下拉加载、快捷预览弹窗与一键下单（One-Click Buy）的流畅度上。
## 7. UI 设计优点
极其成熟的“实用至上”UI 典范，全站 UI 避开了无意义的视觉干扰，将用户的注意力 100% 聚焦在商品与购买行为上。

# 八、京东

**网站：** https://www.jd.com/

## 1. 网站定位
中国领先的自营综合电商平台，强调“正品品质”、“极致物流”与“强烈的促销大促氛围”。
## 2. 版式设计
高信息密度（High Information Density）的典型代表。首屏采用“左侧多级分类 - 中间大轮播图 - 右侧用户与快报”的三栏结构，向下拓展出秒杀、频道、推荐等多层卡片网格。
## 3. 色彩设计
采用高饱和度的 京东红（#E1251B）为主色，大促期间配合烫金、高彩度的营销梯度色；背景纯白，卡片间以微弱阴影或浅灰线分割。
## 4. 图像与图标设计
充斥着大量的营销气氛图、活动氛围框与商品白底图；图标采用面性（Filled）多色微渐变风格，视觉饱和度极高，具有强烈的视觉张力。
## 5. 文字与信息层级
字体阶梯丰富，价格数字（如 ￥99.00）采用专属大字号红色字体突出；标签系统（如“自营”、“秒杀”、“券”）极其丰富，通过标签框颜色区分信息属性。
## 6. 交互与动态效果
极其丰富的营销微交互。包括秒杀倒计时动态更新、悬停卡片图片放大、顶栏悬停吸顶、右侧悬浮挂件（侧边栏客服与购物车）等。
## 7. UI 设计优点
将“逛”与“刺激消费”的视觉心理学发挥到极致，信息呈现极其高效，营造出极其热烈的商业氛围。
## 8. 我的第一印象

> 感觉像是把线下的百货市场“搬”进了线上，顺带让超市里的老年人全部变成了 **“秒杀高手”** 和 **“砍价高手”“**

# 九、南京大学

## 7. UI 设计优点
品牌色彩（南大紫）贯穿始终，典雅的视觉气场与百年名校的历史厚重感结合得非常好。

# 十、Caltech

**网站：** https://www.caltech.edu/

## 1. 网站定位
全球顶尖的理工科研究型大学，强调前沿科学突破、硬核创新与颠覆性科研成果。
## 2. 版式设计
打破传统的“杂志化”现代视觉排版。弃用了陈旧的列表堆叠，采用全屏大图、错落有致的网格切割与巨型标题，更像是一本前沿科学杂志。
## 3. 色彩设计
采用鲜艳亮丽的 加州理工橙（#FF6C00）作为品牌主色，搭配纯黑、纯白与深灰，视觉冲击力极强，凸显科技的火花与活力。
## 4. 图像与图标设计
图像质量极高，充斥着高能物理实验室、太空探索（JPL）、显微微观图像与硬核科研人员的工作照；图标极简，绝不抢镜。
## 5. 文字与信息层级
使用高对比度的无衬线粗体字，文章标题极具震撼力。文字信息层级扁平，突出“突破性新闻（Breakthrough News）”。
## 6. 交互与动态效果
现代感十足。滚动时带有优雅的图片微放大（Zoom-in）与文字浮现效果，支持流畅的响应式屏切。
## 7. UI 设计优点
完全摆脱了传统高校网站的枯燥感，用前沿的现代 UI 语言将“硬核科学”包装得极其酷炫与富有吸引力。
## 8. 我的第一印象

> 像我小时候看的千禧年英语杂志，当时就觉得里面的人动作好夸张哦，现在也是一样的感觉。

# 十一、YouTube

**网站：** https://www.youtube.com/

## 1. 网站定位
全球最大的视频分享与流媒体平台，极度强调“内容即 UI（Content as UI）”与个人化流式推荐。
## 2. 版式设计
极致的自适应流式网格（Fluid Grid）。根据用户屏幕宽度，自动将视频卡片从每行 2 个扩展至 6 个；左侧为可折叠的响应式导航抽屉。
## 3. 色彩设计
提供纯白（Light）与深灰黑（Dark #0f0f0f）两种模式。采用经典 YouTube 红（#FF0000）作为 Logo 与播放进度条，UI 背景极度干净，避免干扰视频本身。
## 4. 图像与图标设计
UI 几乎没有多余图像，16:9 的视频缩略图（Thumbnail）就是最核心的视觉图像；图标采用统一的 Material Design 极简单色面性/线框图标。
## 5. 文字与信息层级
采用 Roboto 字体。视频标题限制为 2 行，通过字号与颜色深度精准区分“视频标题 - 频道名称 - 播放量与时间”。
## 6. 交互与动态效果
行业顶级的微交互体验。鼠标悬停缩略图自动无声预览视频，播放器支持悬浮小窗（Picture-in-Picture），拖拽进度条带有精准时间轴帧预览。
## 7. UI 设计优点
UI 极度退后，让位给内容本身；流式网格适配完美，极佳地承载了海量视频信息的无缝呈现。
## 8. 我的第一印象

> 很标准的，视频网站，别的没了。

# 十二、Bilibili

**网站：** https://www.bilibili.com/

## 1. 网站定位
中国年轻人的文化社区与视频弹幕网站，兼具视频流、二次元文化、直播与社交属性。
## 2. 版式设计
高密度的社区型网格布局。首屏包含大型视频推荐轮播、高密度视频卡片矩阵，以及顶部的动态 BANNER 区。
## 3. 色彩设计
标志性的 “哔哩哔哩粉”（#00AEEC 天空蓝 与 #FB7299 少女粉交替使用），色彩活泼丰富，充满年轻态与二次元活力。
## 4. 图像与图标设计
顶栏 BANNER 常带有精致的二次元插画；视频卡片包含 UP 主头像、硬币数、弹幕数等丰富角标；图标风格活泼萌系。
## 5. 文字与信息层级
文字密度较大，视频卡片下方紧凑地集成了标题、UP主、播放量、弹幕数。通过标签（如“热门”、“直播中”）区分内容形态。
## 6. 交互与动态效果
顶部 BANNER 视差动效（Parallax Banner）是其招牌设计（鼠标左右移动，分层插画呈现 3D 深度感）；视频缩略图悬停可预览进度与弹幕。
## 7. UI 设计优点
极其成功的年轻化 UI 示范，在保持高信息密度的同时，通过丰富的动态细节与二次元元素塑造了极高的社区归属感。
## 8. 我的第一印象

> 板块清晰，和youtube等别的视频网站一样，UI的占比并不大。

# 十三、Niconico

**网站：** https://www.nicovideo.jp/

## 1. 网站定位
日本弹幕视频网站鼻祖，带有浓厚的 Web 2.0 时代痕迹与独特的日系 Otaku 文化属性。
## 2. 版式设计
典型的“日式 Web UI”紧凑布局。首页划分为大量的排行列表（Ranking）、分类标签页与新闻块，排版极度密集，视觉上略显复古。
## 3. 色彩设计
以深灰/黑色（#252525）为主色调，搭配白底卡片；点缀色较为多元但缺乏统一的现代色彩规范，整体配色偏向暗调与高对比。
## 4. 图像与图标设计
缩略图多为 4:3 或 16:9 比例，尺寸较小；图标带有早期 Web 时代的像素感或明细线条感，装饰性图像较多。
## 5. 文字与信息层级
文字信息量极大，字号普遍偏小，排版非常紧密；极度依赖文字排行榜（Rank 1-100）来呈现内容，信息视觉层级相对扁平。
## 6. 交互与动态效果
交互较为传统。以基础的页面跳转、Tab 切换与原生的弹幕播放器为主，少有现代化的视差或滚动动画。
## 7. UI 设计优点
 极具时代特色与文化代表性，展现了“日系文字信息流”的独特排版哲学，对于需要展现大量排行榜与分类的社区有参考价值。
## 8. 我的第一印象

> 好省流量，都没什么图片。

# 十四、Wodniack

**网站：** https://wodniack.dev/

## 1. 网站定位
独立开发者/极客的个人技术博客与项目展示站，追求极致的个人风格、代码美学与轻量化。
## 2. 版式设计
极致的单栏极简居中排版（Single-column Minimalist Layout）。摒弃了一切复杂的侧边栏与页眉页脚，高度类似于 Markdown 文档的渲染效果。
## 3. 色彩设计
默认极简暗黑模式（Dark Mode）。以纯黑或深灰（#121212）铺底，以荧光绿、单色纯白或淡蓝作为代码高亮与链接色，色彩纯粹无污染。
## 4. 图像与图标设计
极少使用装饰性图片，仅在项目展示中使用结构图或架构截图；图标极少，多采用纯文本符号（如 ->, #, [x]）代替图形图标。
## 5. 文字与信息层级
排版艺术（Typography）即 UI。高度依赖系统等宽字体（Monospace，如 JetBrains Mono, Fira Code），通过字号阶梯、加粗与引用块（Blockquote）建立清晰的信息流。
## 6. 交互与动态效果
极轻量。仅包含平滑的页面过渡、极其微弱的链接 Hover 下划线动画，网页加载速度达到毫秒级。
## 7. UI 设计优点
摒弃一切商业噪点，回归阅读与代码本身，展现了纯粹的技术优雅与极致的加载性能。

# 十五、横向比较

  * 信息密度与设计哲学（Information Density）：
    * 低密度/感官驱动： Apple, Caltech（用留白、大图和视差动画创造沉浸感与品牌溢价）。
    * 高密度/效率驱动： Amazon, 京东, CSDN（用满屏的卡片、排行榜与标签争夺注意力，提升转化与检索效率）。
  * 东西方 UI 设计语言差异（East vs. West）：
    * 欧美网站（Apple, USA.gov, GitHub, Caltech）： 倾向于模块化、极简主义、大字号、单栏/少栏卡片，遵循无障碍规范（Accessibility/USWDS）。
    * 中日网站（京东, Bilibili, Niconico, CSDN）： 倾向于高密度信息呈现、热烈的视觉氛围、丰富的多级分类与高饱度色彩。
  * 商业 vs 政务 vs 极客的 UI 诉求：
    * 商业网站： 动态与色彩极具侵略性，引导购买与点击（如京东红、Amazon橙）。
    * 政务与学术： 强调庄重、稳定、高对比度与权威感（如中国政府网的红/蓝配色与无障碍设计）。
    * 极客个人： 摒弃繁复装饰，回归 Typography（文字排版）与性能极致（如 wodniack.dev）。
